# AstroGate 管家

当前版本：**iPhone 0.4.34、Android 0.2.3、Windows 连接程序 0.4.37**。Android 支持 Android 10 及以上，可直接安装 APK；复用现有电脑连接程序与加密中转。[Android 使用和构建说明](Android/README.md)。

Windows 0.4.37 修复手机排队消息的图片缩略图显示，保留模型使用的完整原图；优化桌面大快照分块接收，减少空闲/离线时多余的历史扫描。手机 App 无需重装。

Windows 0.4.36 修复长对话读取过久使手机超时、模型和发送入口不可用的问题。历史按时间预算分批返回，可继续加载更早记录；历史读取不再阻塞订阅、模型、心跳和发送请求。现有手机 App 无需重装。

iPhone 0.4.34 修复进入对话时页面任务取消导致 `Swift.CancellationError`、模型和发送长期不可用的问题。会话连接独立于页面任务，同一对话合并连接请求，切换后忽略旧响应；连接未就绪时自动恢复，并提供“重新连接对话”入口。

Windows 0.4.35 修复桌面握手超时、异常同步数据导致通道无法自动恢复的问题。重连仅恢复订阅，不重复发送消息；桌面断线期间仍可读取历史，但不把旧轮次结果当作当前任务状态。手机 App 无需重装。

底部入口依次为 **Codex、连接、服务、设置**。Codex 是聊天主页；连接页显示已绑定电脑并支持扫码新建连接，选中电脑后进入 Codex；服务页包含文件管理器和 SSH、SFTP、OpenClaw 服务。原有配对与文件继续保留。

电脑连接程序补丁：兼容 Codex 输出文件卡片，将 PDF 等文件显示为手机可点击的下载链接，并支持对话内文件引用的下载授权。手机 App 无需重装。

0.4.19：AI 中转站填入接口地址和 API Key 后自动获取模型列表，支持搜索、选择、刷新，并保留手动填写模型。选择后保存即可用于服务器 AI 助手。

0.4.17：下载成功卡片仅保留“分享 / 导出”，移除签名与打开文件按钮；左侧抽屉收窄至屏幕的 74%（最多 300 点），移除置顶对话区域及置顶入口。

本版增加同步到电脑的对话重命名；发送图片独立显示在文字气泡上方，移除“你”标签；最终回复在分支按钮右侧显示电脑记录的完成时间。已发送的原生附件支持跨目录预览。

SwiftUI 文件管理器，支持本地文件浏览与操作、文本编辑、双窗口、SFTP、SSH 终端、Codex 电脑连接和 OpenClaw 聊天。

## 下载与签名配置

Windows 便携包请到 [Releases](https://github.com/zhaoshi2000/Codex-Mobile/releases) 下载，解压后双击 `Open AstroGate Connect.cmd`。电脑需打开并登录 Codex，首次使用填写中转 WSS 地址和连接密钥。

iOS 源码版本为 0.4.19（26），最低支持 iOS 17。请在 Xcode 工程中配置自己的 Bundle ID、Team 和 Provisioning Profile，随附脚本与 ExportOptions.plist 中的 YOUR_* 占位符也需替换为同一套签名配置。GitHub Actions 手动构建需要 IOS_P12_BASE64、IOS_P12_PASSWORD、IOS_PROFILE_BASE64 三个仓库密钥。

公开仓库提供源码与 Windows 包。iOS 安装需自行使用有效证书签名，Ad Hoc 分发要求设备已登记到描述文件。

## 在 Mac 上自行打包

需要 macOS、Xcode、OpenSSL 3，以及访问 Swift Package Manager 依赖仓库的网络。首次使用 Xcode 时须完成许可和组件初始化。

把证书 ZIP 中的文件放入工程的 `Signing/` 目录，命名为：

```text
Signing/
├── signing.p12
├── signing.mobileprovision
└── password.txt
```

在工程目录运行：

```bash
chmod +x build-ios.sh
./build-ios.sh
```

脚本会核对描述文件与证书，将所提供 P12 临时转换成 macOS 可导入的格式，创建临时 Keychain，执行 Release Archive 并导出 Ad Hoc IPA。输出位置为 `Build/export/iFilePlus.ipa`。临时签名文件与 Keychain 会在脚本退出时清理。`Signing/` 内的原始文件由使用者自行保管。

工程也提供 `.github/workflows/build-ipa.yml`，可在 macOS GitHub Actions 运行。该工作流需要 `IOS_P12_BASE64`、`IOS_P12_PASSWORD`、`IOS_PROFILE_BASE64` 三项 Actions 加密密钥；其中 P12 必须是 macOS 可导入的格式。源码包不含证书、私钥、密码或描述文件。

## 依赖与限制

- Citadel 0.12.1、swift-nio-ssh、SwiftNIO、swift-crypto 用于 SSH/SFTP。
- 本地文件访问受 iOS 沙盒和 Files 授权范围限制。
- 文件传输入口仅保留 SFTP；旧 FTP 配置不会显示或自动连接。
- Markdown 文件使用纯文本编辑器，没有渲染预览。
- SSH 终端支持基本 ANSI 输出，复杂 TUI 的光标移动和屏幕重绘仍可能显示不完整。
- SSH 私钥暂不支持带 passphrase 的密钥。
- 大文件传输、后台任务、断点续传和网络中断恢复尚需真机压力测试。
